# Onmyoji AutoBot (AutoYYS) V1.2

阴阳师「通用战斗模板」挂机工具。按 `docs/` 中的 PRD/TDD 分层架构实现。

## 启动

双击 `启动AutoBot.bat`（内部 `pythonw main.py`，非管理员会自动弹 UAC 提权——
提权是为了避免 DPI 虚拟化导致截图识别错位，请勿拒绝）。

## 使用

1. **运行模式**：选「后台」时填窗口标题关键词 → 「刷新窗口」→ 下拉选目标窗口
   → 可先点「测试」（保存一张客户区截图到 `logs/`，并向窗口中心发一次后台点击）；
2. **战斗配置**：用预置模板（魂11/御灵/业原火/活动/结界突破/困难28通用）或自建：
   - 5+ 张图（战斗开始必填；胜利/失败/结算确认/备选开始图可留空=跳过该步检测），
     支持「浏览」或「截图」框选，右侧有缩略预览，各带置信度；
     截图保存为 `{模板名}_{字段}.png`（如 `结界突破通用_victory.png`），
     **同模板同槽位重新截图即覆盖更新，跨模板互不影响**；
   - 「进入战斗后点击式神」：勾选并设置式神图片后，进入战斗会自动
     识别该式神并点击一次（每场战斗只点一次）；
   - 「备选开始图」(勾选):与主开始图任一命中即点,适配同一按钮的两种外观;
   - 「第二段图」(勾选):点完开始图后自动找它并单击(如结界突破的"进攻"),
     之后才等胜负——预置模板「结界突破通用」即此流程;
   - 「找不到图时自动滚动」(勾选):滚轮(格数可负)或拖拽(起/终点全屏点选),
     每隔 N 秒触发一次,用于需要滑动列表才能看到按钮的界面;
   - 「副本入口/结束」(可选,双层循环如困难28探索):勾选入口图1[→入口图2]
     (每段带"点击后等待"),开始图循环战斗;勾选「副本结束图」后,找挑战时
     顺带检测,识别到就点击并自动重新进入副本(挑战图与结束图同屏时优先打挑战);
   - 「找图超时」：超过设定秒数（默认100，0=不启用）找不到战斗开始图时，
     自动点击「激活点击坐标」（全屏点选截取）尝试重新激活；若重新激活后
     一个周期内仍找不到，自动保存现场截图并停止；
   - 次数上限 / 战斗超时 / 超时点击坐标（「截取坐标」全屏点选）；
   - 每 N 次休息 M 秒（范围随机，拟人化）；找不到开始图的 continue/stop 策略；
3. 「另存为+保存」把当前配置存为模板（`profiles/*.json`），下次启动自动恢复
   上次运行配置；
4. ▶ 开始 / ⏸ 暂停 / ⏵ 恢复 / ■ 停止（暂停停止均即时生效）；
5. 「＋ 新建标签页」多开：每页一个独立会话，可绑不同游戏窗口；
   标签标题实时显示进度，关闭页面自动停止该页。

## 架构

```
gui/        Presentation：多标签页、配置界面、日志
worker/     Worker 线程：按 detect_interval 驱动控制器，可暂停/恢复/停止
controller/ AutomationController：FSM 驱动的 tick 循环（无阻塞等待）
state/      GameState 状态机 + 转换表
vision/     ScreenCapture(PrintWindow+GDI防泄漏) / TemplateMatcher(mtime缓存) / ScreenDetector
input/      InputController：前台 pyautogui 拟人化 / 后台 PostMessage + 坐标映射
window/     WindowManager：窗口枚举/校验/客户区
profiles/   BattleProfile 配置管理（预置/保存/加载/上次配置）
core/       领域模型 / 异常 / 统计
debug/      DebugManager：错误现场截图 + GDI 对象数诊断
```

与文档的实现偏差及补充功能见 `docs/DEVIATIONS.md`。

## 测试

```bash
python -m pytest tests/ -q
```

40 项测试全部 Mock（窗口/截图/识别/输入），不依赖真实游戏窗口；
控制器注入虚拟时钟，规避 Windows 计时器精度问题。

## 排错

| 现象 | 处理 |
|---|---|
| 后台截图全黑/匹配低分 | 确认以管理员运行；看 logs/ 错误现场里的 GDI 对象数是否异常增长 |
| **窗口最小化** | **不支持**——最小化后客户区为 0x0，任何截图方式都拿不到画面。用「遮挡」（窗口被其他窗口盖住）代替最小化，日志会提示"窗口可能已最小化"，恢复窗口后自动继续 |
| 长时间无交互后持续黑帧 | 游戏自身进入空闲省电，日志会持续提示；点击游戏/重启游戏即可恢复 |
| 后台点击无反应 | 「测试」按钮验证；MuMu 多开时确认绑定的 HWND 正确 |
| 识别坐标错位 | 确认以管理员运行（UAC 提权被拒绝会导致 DPI 虚拟化） |

> 已知边界：后台模式支持「遮挡」不支持「最小化」。PrintWindow 会渲染整个窗口
> （含标题栏），项目内已做客户区裁剪对齐（否则识别整体偏移一个标题栏高度）。
