# 实现偏差与范围说明（DEVIATIONS）

对照 docs/01-06 文档的实现偏差记录。所有偏差目标：在不损失架构要求的前提下，
复用 YYSGUI 已验证的实战代码与经验。

## 技术栈偏差

| 文档要求                 | 实际实现                  | 原因                                                                                                                           |
| ------------------------ | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Python 3.11+             | 3.9+ 兼容写法             | 当前环境为 Python 3.9.7                                                                                                        |
| PySide6 + QThread/Signal | tkinter + threading/after | PySide6 未安装；YYSGUI 的截图框选/预览/标签页均为 tkinter 已验证实现，迁移零损耗。分层架构不受影响（GUI 只是 Presentation 层） |
| pywin32                  | ctypes                    | YYSGUI 已用 ctypes 实现全部 Win32 调用，少一个依赖                                                                             |

## 范围偏差

- 仅实现「通用战斗模板」流程（对应 YYSGUI 模式 h）。原 a-g 模式按需求明确排除。
- FSM 的 run_once 为无阻塞 tick 模型：所有等待用时间戳+提前返回实现，
  而非文档隐含的单次长流程。暂停/停止因此始终即时生效（<= 一个检测间隔）。

## 文档未覆盖、按需求补充的功能（对应 YYSGUI 已实现能力）

### V1.1 追加：战斗中点击式神（需求新增，文档无）
- BattleProfile 新增 shikigami_enabled / shikigami_img / shikigami_threshold
- WAIT_BATTLE 期间随胜负检测一并识别式神图，命中即点击一次；
  每场战斗重置标记（进战斗后只点一次，避免连点）；
- 未勾选/未放图时不请求该检测（不耗 CPU、不误触）；
- GUI 在战斗配置区提供勾选框 + 图片行（浏览/框选截图/预览/置信度），
  启动时校验"勾选但未设图"并阻止开始。

### V1.1 追加：找图超时自动激活（需求新增，对应补上文档缺口 048/051 的一半）
- BattleProfile 新增 find_timeout（默认100秒，0=不启用）/ find_timeout_click（激活坐标）
- FIND_CHALLENGE 找不到开始图超过阈值 → 点击激活坐标一次（后台自动转客户区），
  重新开一个计时窗口继续找；再超时 → 保存现场截图 + ERROR 自动停止；
- 未设置激活坐标 → 首次超时直接停止；休息时间不计入超时窗口；
- 每一轮挂机（重新进入 FIND_CHALLENGE）重置"已激活"标记；
- GUI 提供 找图超时(秒) + 激活点击坐标(全屏点选截取) 控件，随模板持久化。

### V1.1 追加：战斗等待期异常应对三层（需求新增：网络卡/点击被吞/卡死）
- **没进战斗自愈**：WAIT_BATTLE 期间顺带检测开始图；进战斗 reenter_check 秒
  (默认8,0=关闭)后仍看到开始图 → 判定点击未生效,自动重点开始图
  (最多3次,超过则存现场),比"超时坐标"更快更准;自愈会重置看门狗计时
  (自愈动作本身即进展);
- **看门狗**：battle_timeout=0(不限时等胜负)时的兜底——watchdog_timeout 秒
  (默认600,0=关闭)无任何动静 → 存现场截图 + 按 error_action 处理
  (continue 时点超时坐标后回找挑战);
- **胜负图两拍确认**：胜负图连续两拍都命中才处理,防战斗动画中截获单帧假命中
  导致误点/漏计;
- 异常处理闭环: 没进战斗→自愈重点;真卡死→战斗超时(超时坐标);
  不限时卡死→看门狗;掉线/体力不足→(待做)异常图槽位。

### V1.1 追加：模板图片语义化命名(取代时间戳快照)
- 截图保存为 `{模板名}_{字段}.png`(如 结界突破通用_victory.png),同名覆盖;
- 覆盖语义辨析:旧 bug 是"跨模板"覆盖(必须防);同模板同槽位重截=更新,
  覆盖即清理,且 mtime 缓存自动重载,安全;
- 非法文件名字符替换为下划线,未命名模板用"未命名"兜底;
- 截图后另存为改名,图片保持原文件名(引用仍有效);
- 旧时间戳快照(gen_*)引用继续有效,新截图不再产生时间戳文件。

### V1.1 追加：备选开始图 / 第二段进攻图 / 滚动拖拽查找（补齐 YYSGUI 模式e 结界突破能力）
- 三个勾选能力,不勾=零影响:
  - ☑ 备选开始图(alt_*):与主开始图任一命中即点那张(button_choice 语义);
  - ☑ 第二段图(second_*):点完开始图后找它单击一次再等胜负

## 已知缺口状态说明

- **自愈已全面覆盖开始图双形态与两段式战斗**（V1.1.2 补齐）：
  - (a) `FIND_SECOND` 阶段若第一段点击被吞，自动兼测开始图（主/备），超时后自愈重击开始图重新展开；
  - (b) `WAIT_BATTLE` 阶段若第二段进攻点击被吞，自动兼测第二段图（进攻），超过 `reenter_check` 后自愈重点第二段图；
  - 以上两处自愈均设上限 3 次，超过则自动保存错误现场，彻底规避了结界突破中的卡顿与超时停滞。
- **异常图槽位（掉线重连/体力不足弹窗）**：规划在通用弹窗自愈模块中推进。
